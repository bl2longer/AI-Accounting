## 应用界面概述

AI智能记账应用的界面主要包括以下几个部分：

1. **主界面（Home）**：应用入口，提供添加新消费记录和查看最近记录的功能
2. **数据输入界面（Input）**：支持多模态数据输入的界面
3. **确认界面（Confirm）**：显示AI识别结果并请求用户确认
4. **记录查看界面（Records）**：查看和管理历史消费记录
5. **报表界面（Report）**：生成和查看消费报表

## 添加消费记录

### 步骤1：选择输入方式

在主界面点击"添加新消费记录"按钮，进入数据输入界面，选择以下输入方式之一：

1. **拍照输入**：点击相机图标，拍摄收据或发票照片
2. **语音输入**：点击语音图标，录制消费描述
3. **文字输入**：点击文字图标，手动输入消费描述

### 步骤2：确认识别结果

系统使用AI处理输入数据后，会显示识别结果，包括：

- 商家名称
- 消费日期
- 消费总金额
- 消费项目列表

对于AI不确定的信息，系统会标记并请求用户确认。用户可以：

- 确认正确的信息
- 修改不正确的信息
- 添加缺失的信息

确认无误后，点击"保存记录"按钮保存消费记录。

## 查看消费记录

在主界面点击"查看所有记录"按钮，进入记录查看界面。在该界面，用户可以：

1. **浏览记录**：按时间顺序查看所有消费记录
2. **筛选记录**：使用筛选选项按日期、商家或分类筛选记录
3. **查看详情**：点击记录查看详细信息
4. **编辑记录**：修改已保存的记录信息
5. **删除记录**：删除不需要的记录

## 生成报表

在记录查看界面点击"生成报表"按钮，进入报表界面。在该界面，用户可以：

1. **选择时间范围**：查看本周、本月或本年的消费报表
2. **查看总览**：查看总支出和消费次数
3. **查看分类支出**：查看按消费分类的支出饼图
4. **查看商家支出**：查看按商家的支出排行
5. **查看支出趋势**：查看按日期的支出趋势图

详细的报表说明请参阅[报表详解](./reports.md)。
