# 报表详解

## 概述

AI智能记账应用提供多维度的消费报表，帮助用户分析消费模式和趋势。报表界面支持按不同时间范围（周、月、年）查看报表数据。

## 报表类型

### 1. 总览

总览部分显示选定时间范围内的总体消费情况，包括：

- **总支出**：所有消费记录的金额总和
- **消费次数**：消费记录的总数量

### 2. 分类支出

分类支出部分使用饼图展示不同消费分类的支出比例，帮助用户了解消费结构。每个分类显示：

- 分类名称
- 支出金额
- 占总支出的百分比

### 3. 商家支出

商家支出部分使用条形图展示支出最多的商家（Top 5），帮助用户识别主要消费场所。每个商家显示：

- 商家名称
- 支出金额
- 消费次数

### 4. 支出趋势

支出趋势部分使用条形图展示按日期的支出变化，帮助用户了解消费模式的时间分布。图表显示：

- 日期
- 每日支出金额

## 时间范围筛选

报表界面提供三种时间范围筛选选项：

1. **本周**：显示最近7天的消费数据
2. **本月**：显示当前月份的消费数据
3. **本年**：显示当前年份的消费数据

## 数据来源

报表数据来源于用户保存的消费记录，通过后端API从数据库中查询和聚合。主要的数据处理包括：

1. **按分类聚合**：计算每个分类的总支出和消费次数
2. **按商家聚合**：计算每个商家的总支出和消费次数
3. **按日期聚合**：计算每个日期的总支出

## 报表API

报表数据通过以下API获取：

```
GET /api/expenses/summary/report
```

查询参数：

- `start_date`：开始日期（YYYY-MM-DD）
- `end_date`：结束日期（YYYY-MM-DD）

响应格式：

## 图表交互

报表界面中的图表支持以下交互功能：

1. **悬停提示**：鼠标悬停在图表元素上显示详细数据
2. **点击筛选**：点击图表元素可筛选相关数据
3. **缩放**：支持图表缩放查看更多细节

## 报表导出

当前版本不支持报表导出功能。在未来版本中，计划添加导出为PDF或Excel格式的功能。
